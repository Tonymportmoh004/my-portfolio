# My Portfolio

A personal portfolio website for **Tonymportmoh004**, built with semantic HTML, responsive CSS, and lightweight JavaScript.

## Customize

1. Replace `Your Name`, the introduction, project cards, email address, and links in `index.html`.
2. Adjust colors and layout in `styles.css`.
3. Add project images or additional pages as needed.

## Local preview

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deployment

`.github/workflows/pages.yml` deploys the site to GitHub Pages whenever changes are pushed to `main`. In repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if it is not selected automatically.
